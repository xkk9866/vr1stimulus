# Code Artifact

This repository contains the Python source code used for stimulus processing,
model execution, diagnostics, and evaluation in a VR perception study.

## Contents

- `src/`: executable Python scripts and model definitions
- `requirements.txt`: Python package requirements

Data, generated results, figures, manuscripts, supplementary files, and other
submission material are intentionally excluded from this repository.

## Setup

```bash
python -m pip install -r requirements.txt
```

The scripts expect the relevant datasets to be available locally. Dataset
files and access credentials are not included.
